# Complex creative work

Use for a creative project whose unresolved design choices or coordination actually benefit from planning and review. Respect an explicitly requested OpenClaw/Superpowers method; do not impose it on every document, script or configuration edit.

1. Use the supplied brief and existing project context. Ask only about a material unresolved choice; retain an explicitly requested interview or approval checkpoint.
2. For substantive alternatives, describe the tradeoff and settle the design within the user's authority. A request to execute a clear brief already authorizes its ordinary implementation.
3. Plan at the granularity that helps completion. Use the current model inline by default. Delegate only when authorized, supported and independently useful; do not force a fresh agent for every small task.
4. Create the requested artifact, preserve source work, and verify its concrete success conditions. Use test-first creation only when requested or useful to the actual artifact.
5. Continue through authorized implementation and verification. Ask before a new consequential choice or unapproved external action, not merely because a phase ended.

The bundled scripts and templates remain available for an explicitly selected legacy workflow. Resolve them relative to this folder. Their historical examples do not override the current user brief, runtime or authorization. The complete pre-change guide is preserved in the verified skill-library recovery set.
