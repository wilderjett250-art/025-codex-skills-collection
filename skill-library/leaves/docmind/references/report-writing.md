# Report Writing

## Style

Reports should be clear, sparse, and usable without reformatting.

- Start with the conclusion.
- Put findings before background.
- Use short paragraphs or flat bullets.
- Keep each finding self-contained.
- Link every finding to evidence.

## Recommended Structure

1. Scope
2. Coverage proof
3. Findings
4. Pending review
5. Method
6. Appendix

## Finding Template

- **Finding**: short claim
- **Location**: exact file and locator
- **Issue**: what is wrong or uncertain
- **Impact**: why it matters
- **Evidence**: extracted text or artifact path

## Clarity Rules

- Do not bury the answer under process narration.
- Do not mix facts and interpretation in one sentence when it can be split.
- Do not use decorative prose.
- If something is incomplete, say so plainly.
