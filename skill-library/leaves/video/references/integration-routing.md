# Optional video integrations

The upstream repository's external integration manuals were not bundled. This map replaces the broken links without claiming either service is installed or authorized.

## HeyGen
Use only if the user chooses HeyGen and its trusted connector/CLI is actually available. Inspect that capability's current schema/docs and account; preserve script, input-media and destination scope. An avatar/video generation can consume paid credits, so do not sign up, upload private media or run it merely because it appears in the tool table. Otherwise use an available authorized route that satisfies the chosen deliverable.

## Hyperframes
Use only when that framework is selected and the actual local project/package or trusted integration is present. Inspect the installed package's entrypoint and documentation before assuming commands, versions or API methods. An unavailable framework is a concrete dependency gap; do not fabricate a tool or silently replace a user's specified framework.
