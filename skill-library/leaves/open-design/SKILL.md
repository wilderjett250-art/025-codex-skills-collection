# Open Design binding
Read the project's .open-design.json if present and resolve the configured content root. Preserve its named system/template and the user's current scope.
If the content root or binding is absent, identify the missing input before changing anything; do not clone a large repository or change storage locations as an implicit design prerequisite.
Use this Skill's existing discovery helpers only when browsing that catalogue is the task. Inspect their help and resolve paths against this Skill directory with Windows-compatible commands.
Load only the selected system/template for the current surface. Do not refresh or reread unchanged bound bodies every turn. For normal app UI or presentations, use the already available specialist instead.
