# Figure Types

## Mechanism Schematic

Use for causal or biological/chemical/computational mechanisms.

Layout: left-to-right or top-to-bottom sequence with 3-5 entities.

Show activation, inhibition, binding, transport, feedback, or transformation only when supported by the source.

## Experimental Workflow

Use for methods, assays, sample processing, and pipelines.

Layout: sample/input -> preparation -> measurement -> analysis -> output.

Avoid fake instrument readouts.

## Study Design

Use for cohort, sample, intervention, observation, or endpoint overviews.

Layout: participants/samples -> grouping -> intervention/observation -> endpoint.

Use generic counts unless exact counts are supplied.

## Assay Pipeline

Use for lab or computational assays.

Layout: material -> assay action -> signal/readout -> interpretation.

Keep readouts symbolic unless real data is supplied.

## Model Architecture

Use for computational models, ML pipelines, simulations, and agent systems.

Layout: inputs -> model blocks -> outputs.

Show only major components. Avoid pretending to know hidden architecture details.

## Comparison Figure

Use for control vs treatment, baseline vs proposed method, healthy vs disease, or before vs after.

Layout: two balanced sides with matched visual grammar.

Use only the exact contrast supported by the source.

## Graphical Abstract

Use for one-paper summaries.

Layout: problem/context -> method/intervention -> core mechanism/result concept -> implication.

Keep the result conceptual; do not invent final numeric outcomes.
