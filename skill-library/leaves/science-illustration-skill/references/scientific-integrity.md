# Scientific Integrity

## Default Rule

Do not fabricate scientific evidence. When source material is incomplete, make a conceptual schematic, not a data figure.

## Never Invent

- Numeric data, plots, axes, p-values, error bars, survival curves, heatmaps, spectra, or statistical claims.
- Microscopy, histology, MRI/CT, gel bands, western blots, flow cytometry plots, electropherograms, instrument readouts, or assay outputs.
- Gene/protein/drug/compound names not supplied by the user.
- Molecular structures, protein conformations, binding poses, reaction mechanisms, anatomical details, species, cell types, or pathways not supplied by the user.
- Clinical claims, efficacy, safety, diagnosis, or causal relationships not supported by the source.

## Allowed Without Data

- Conceptual mechanism schematics.
- Experimental workflow diagrams.
- Study-design overviews.
- Graphical abstracts.
- Symbolic readouts labeled generically, such as "measurement", "signal", "output", or "prediction".

## When User Requests Fake Evidence

Refuse the fabrication briefly and offer a safe alternative:

```text
I can't create fake empirical evidence. I can make this a conceptual schematic with symbolic outputs instead.
```

## When User Supplies Data Or Exact Constraints

Preserve supplied labels, entities, values, and constraints exactly. If exact visual accuracy matters, ask for the source figure, dataset, structure file, or reference image before generating.
