# Two-Level Skill Taxonomy

Use exactly one primary domain to narrow the search. Add a second domain only when it is an independent delivery, integration, risk, or acceptance dependency.

| Domain keyword | Choose it when the task is mainly about | Typical secondary signals |
| --- | --- | --- |
| `project-flow` | scoping, Git/GitHub, handoff, task decomposition, or workspace control | `handoff`, `project`, `workflow` |
| `code-engineering` | language-level implementation, refactoring, CLI, algorithms, or code conventions | language/framework, `test`, `CLI` |
| `frontend-ui` | web UI, visual implementation, design system, Figma, or screenshot parity | `React`, `Vue`, `CSS`, `Figma` |
| `backend-api` | server routes, provider integrations, authentication, or backend framework work | `API`, `FastAPI`, `Django`, `Spring` |
| `data-database` | schemas, SQL, migrations, analytics, dashboards, ETL, or spreadsheets | `Postgres`, `MySQL`, `Prisma`, `Excel` |
| `devops-runtime` | deployment, containers, server/network/runtime, performance, or production checks | `Docker`, `Nginx`, `SSH`, `systemd` |
| `browser-desktop` | existing browser session, desktop automation, web-flow debugging, or browser screenshots | `Edge`, `Chrome`, `Playwright`, `Windows` |
| `documents-media` | DOCX/PDF/PPT, graphics, photo/video/audio, rendering, or media QA | `Word`, `PDF`, `slides`, `video` |
| `research-knowledge` | academic work, source research, knowledge retrieval, papers, or citations | `literature`, `paper`, `citation`, `PubMed` |
| `ai-ml` | LLM/agent/MCP architecture, prompts, model evaluation, training, or AI media | `agent`, `MCP`, `LLM`, `model` |
| `hardware-iot` | devices, embedded work, CAD, firmware, equipment, or physical acceptance | `ESP32`, `serial`, `CAD`, `device` |
| `mobile-interactive` | Android/iOS/Flutter, Unity, games, or native/mobile builds | `Kotlin`, `Swift`, `Flutter`, `Unity` |
| `security-quality` | security review, compliance, static analysis, tests, quality gates, or audit findings | `security`, `scan`, `QA`, `CodeQL` |
| `business-ops` | market/content/sales/CRM/finance/logistics/product operations | `SEO`, `customer`, `billing`, `inventory` |

The catalog keeps full Skill names and short trigger descriptions. Domain selection narrows candidates; it does not authorize a Skill or override project rules.
